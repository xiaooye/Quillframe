# 实施计划

1. 保留已停止运行、准确源码、原始失败结果及累计预算，确认没有模型 worker 或 executor 仍在执行。
2. 实现可选 Agent 请求时限和 HTTP 截止时间传递；并行实现当前 relay packet 与 CLI 截止时间检查。生产中的较长配置仅用于两个完整正文阶段。
3. 审查时间运算、序列化、证据绑定、迟到结果处理、源码与版本边界，以及 AI 判断权限不变。使用确定性时钟、假进程或本地测试服务器验证，不调用真实模型。
4. 完成全套检查，复核并提交准确受测文件，将部署源码绑定到该提交。如实记录局限，不声称已跑通或质量改善。
5. 仅在明确的剩余授权内启动新生产运行；保留每次尝试，通过预资格后进行新的独立审查，仅交付 Core 释放的原始正文。

本次实现不会让已确认的失败结果变成可续跑状态。不得从修复传输的决定推断出额外模型调用授权。
