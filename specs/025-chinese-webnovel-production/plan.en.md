# Implementation Plan

## Sequence

1. Freeze the actual working-tree source into the isolated Linux checkout. Verify secure storage as the ordinary runtime user.
2. Finish the whole-novel project contract, atomic creation, chapter/document identity, versioned plans and settlement dependencies.
3. Finish durable execution, cancellation guards and causal model-stage wiring. Bind selected project preferences and reader intent into the context fingerprint.
4. Connect reader expectations and planning horizons without leaking future plans into blind review. Render evidence in Plan, Story and Review.
5. Finish project learning, its trusted semantic executor, activation receipts and package contents.
6. Finish safe editing, verified artifact download and ordered book export. Run deterministic suites, browser checks and then genuine GPT acceptance.

## Interfaces

Core supplies `chapter.list/create`, `plan.inspect/save`, `story.inspect`, reader-expectation inspection/application, learning feedback/preference operations, durable `author.run.status/resume/cancel`, `publication.artifact.get` and `publication.collection.build`. Writes use explicit authorization where consequential, exact identities, before-version checks and idempotency receipts. Browser requests cannot attest model results.

## Verification and rollout

Use new synthetic consumer projects outside the framework; preserve existing local state. Ship no compatibility adapter. Keep implemented, unit-tested, browser-verified and real-model-verified claims separate. Correct research-register citation mismatches and pin new repository observations to exact commits. No cloud deployment or third-party skill installation occurs in this slice.
