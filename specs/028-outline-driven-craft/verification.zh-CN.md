## 真实证据与限制

[六组对照流程](../../evals/OUTLINE_CRAFT_ABLATION.zh-CN.md)已经完成：6 次共用场景投影、12 次 Raw Draft、12 次 Surface，共 30 个可观察 CLI 轮次。30 次全部提交成功，宿主线程身份各不相同；模型失败和重试均为零。三批匿名材料共含六组，未导出版本映射。当前待办关卡是作者盲读。

作者明确要求重置的是**本地实验轮次**：本轮目前包含上述 30 次调用。原有 185 次计入预算的尝试、账本原字节和独立派发证据仍然保留并绑定哈希；服务商／账户用量未清零。已有 192 次上限仍然有效，未安排额外调用。

冻结实现源码清单覆盖 1,040 个文件，以 `22a9b21dc93099882f87ce546c3ed8abb31abd76` 加上如实登记的未提交改动为基础。清单 SHA-256 为 `37deb6df62c5d91d31c8c820d5836fbc4d8d832061b2d31574ce5ba78e2b4cc4`。首次通道启动在读取 WSL UNC 导入路径时卡住，尚未启动 CLI／模型；未使用的请求和操作器均已保留。改用哈希匹配的本地源码路径后，已有 relay 恢复；恢复过程中没有抹去或重跑模型尝试。

两版均使用 `gpt-5.5`、`xhigh` 推理、仅含本次材料的新 CLI 进程、相同声明的 token 预算及有界截止时间。通道在返回后检查实际 token 用量，不声称实现了服务商侧的输出 token 硬上限。采样默认值与服务商模型修订未固定。真实 CLI 轮次身份、净化后的生命周期证据和原始输出私有保存；记录的一次调用指观察到的一次 CLI 轮次，不等于独立观测了服务商内部 HTTP 重试次数。操作系统隔离未获独立证明。

宿主报告 30 个轮次合计 297,014 个输入 token 与 58,873 个输出 token；单次最大输出为 2,548 个 token，低于其声明的单次上限。这些只是宿主遥测，不是服务商计费用量重置，也不是内部重试次数的独立观测。12 份最终样稿各含 1,471–1,848 个 Unicode 码位。任务中的 1,200–1,600 字是软目标，不是确定性关卡；没有裁剪或重生成样稿，因此实际长度仍可能成为偏好混杂因素。

生成先后顺序由私有种子确定，六组中恰为 4／2，而非完全平衡，因此可能存在顺序效应限制。盲读展示方向使用另一份盐值，严格保持 3／3 平衡；这两项汇总数量都不暴露具体组的映射。

作者尚未给出偏好，没有指定胜出版本，也不声称提升。方法适用性在盲读后另行评估。这是共用场景投影、隔离正文实现差异的实验，不是全生产链比较。样稿不具备生产发布、Canon、接受、结算、持久口味或 General Craft 推广权限。默认指导保持不变。
