# 018 · Publication Playground — Specification

## Primary mode

`SYSTEM-IMPROVE`

## Problem

The product-site `/publication` route is still a presentation mock: prose, `exact text`, artifact state, and provenance are hard-coded. The preview also shows broken/garbled branding in the reported surface. The repository already owns a single real publication implementation in `publication/compiler.py`, so a second TypeScript exporter would create drift.

A separate known debt exists: Studio's Publication route and the current Host Bridge `publication.preview` arguments disagree, while Core `publication.build` still persists only `md/txt`. That authority-path migration is explicitly out of scope here.

## Goal

Turn `/publication` into a real browser-local playground that:

- uses the repository SVG brand mark;
- accepts `.json/.txt/.md/.markdown` uploads and pasted input;
- executes the exact repository `publication/compiler.py` in a module Web Worker through Pyodide;
- accepts publication source JSON and `quillframe_agent_result_v1.final_text`;
- derives exact UTF-8 SHA-256 integrity fingerprints for plain text/agent-result adapters;
- builds real Clean Text, Web, Print, and EPUB artifacts;
- previews compiler output rather than fixture prose;
- downloads the real generated bytes;
- exposes source/artifact fingerprints, text round-trip state, and EPUB internal validation;
- always marks upload/playground input `source_authority_verified=false` and `authority=false`;
- performs no Project, Canon, SQLite, acceptance, or settlement write;
- never claims internal EPUB validation is release conformance; release EPUB still requires external EPUBCheck.

## Architecture

`SolidJS → browser-local source adapter → module Web Worker → Pyodide → exact publication/compiler.py → quillframe_publication_ir_v1 → real artifacts → preview/download`

Pyodide owns runtime execution only. Publication rules remain owned by `publication/compiler.py`.

## Acceptance

- Product quality and build pass.
- ProductApp contains no old publication fixture prose.
- Worker imports `publication/compiler.py?raw` rather than reimplementing compilation.
- Real browser download path exists.
- Preview branding uses the repository SVG mark.
- Typed/result surfaces retain all authority=false boundaries.
- No direct SQLite/Core mutation path is introduced.
