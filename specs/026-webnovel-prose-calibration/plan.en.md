# Implementation and verification plan

Establish deterministic wiring and authority boundaries before bounded model validation. Distinguish engineering correctness, model judgments, and author approval throughout.

1. Freeze the baseline, inspect current execution and budget, and verify no active executor.
2. Implement writing/context wiring, contract updates, and complete Chinese calibration fixtures in parallel. Add an exact source path for author-requested revision of a released draft.
3. Test actual jobs, public positioning, hidden-label isolation, original-draft preservation, authorization, idempotency, fingerprint invalidation, and historical-contract boundaries. Do not replace literary judgment with regex scoring.
4. Run documentation checks and the complete deterministic suite, review the diff, commit, and record exact source identity. Normal checks make no model calls.
5. Separately execute small blind-calibration and generation comparisons within the existing cumulative budget. Retain failures and disagreements without reviewer shopping.
6. Before relying on a new native output-schema mechanism, use a separately charged, single-call compatibility probe. Validate the actual registered job, CLI output and original domain binding; do not treat the probe as literary evaluation or release evidence. Further exact-value narrowing with the same exercised schema primitive requires binding regressions and an explicit coverage statement, not an additional compatibility claim.
7. Start a separate production run under the current authorization: `REVISE` for an existing released draft, or a new native project and `DRAFT` for a newly supplied outline. Complete generation, qualification, independent review, and Core release. Deliver only exact released prose; author acceptance and settlement remain explicit subsequent actions.

Verify remaining budget before dispatch and reserve the required independent review. Preserve original inputs and execution state across interruption; never recreate a run to conceal failures or reset accounting.
