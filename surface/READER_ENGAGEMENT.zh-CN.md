# Reader Engagement · 框架级正向质量模型

## 目的

Surface Fundamentals 回答：

> 正文有没有 malformed、机械 AI 味、因果过薄、假精致等问题？

Reader Engagement 回答：

> 为什么读者愿意继续读、获得回报、在意人物，并感到故事真的在移动？

一章可以所有 Surface Hard Rule 都过，却依然因为安全、流程化、可预测、情绪无力、缺少 propulsion 而失败。

```text
Surface Safety = 质量地板
Reader Engagement = 正向质量模型
Genre / Platform Profile = 阈值与权重
Project / User Profile = 个性化强调
```

下面这些 mechanism 是通用的；Profile 调强度，不需要重新发明质量模型。

# RG Family

## RG-01 · ACTIVE READER QUESTION / 活跃读者问题

维持至少一个符合当前作品形态的近程 live question。

例如：
- 一个具体目标能不能完成？
- 另一个人会怎么选？
- 哪个隐藏事实会改变当前理解？
- 代价到底是什么？
- 关系、权限或身份会不会变化？
- 当选项越来越少时，角色会怎么做？

这个问题应该随着章节推进而变尖、分叉、转向，或被一个更重要的问题替代。单纯重复同一个倒计时不叫 evolution。

文学/安静型 Profile 可以让问题更隐性；连载/高抓力 Profile 要求更强的近程 pull。

## RG-02 · PRESSURE LADDER / 压力阶梯

Major beat 应该至少通过以下一种方式改变“可选项地图”：

- 缩窄可行选项；
- 暴露/增加代价；
- 引入可信阻力；
- 暴露遗漏或错误；
- 迫使角色提前做选择；
- 解决一个压力，同时打开更重要的压力；
- 改变旧信息的意义；
- 改变关系权限或信任；
- 让“不行动”本身开始付出代价。

不要机械添加 obstacle。压力应来自人物、制度、资源、环境、之前的选择、知识边界或已 planted state。

## RG-03 · REWARD CADENCE / 回报节奏

读者需要阶段性得到东西，而不是只等最终“剧情正确”。

Reward 可以是：
- 能力兑现；
- 有用信息或 reveal；
- 情感亲密；
- 社会关系反转；
- 幽默；
- callback / recognition；
- 身份或权限提升；
- 一个令人满意的反驳被解决；
- 早先细节真正变得有用；
- 出乎意料但合理的人物选择；
- Profile 重视时的审美/感官愉悦。

不设固定配额。判断读者在场景/章节结束前是否获得了值得投入注意力的回报。

## RG-04 · FRICTION OVER PROCEDURE / 摩擦优先于流程

当任务包含大量 routine operational steps 时，优先展开：

- 人们意见不合；
- 信息不完整；
- 某个错误被抓到；
- 责任/风险发生转移；
- 时间或资源真正变成约束；
- 必须在不完美选项之间做选择；
- 关系改变了任务能不能继续。

Routine procedure 应压缩，除非该 genre/profile 明确承诺“流程本身就是乐趣”。

## RG-05 · CHARACTER-OWNED ENERGY / 角色自带能量

重要角色应该通过自己的 agenda、能力、偏见、幽默、恐惧、欲望、社交策略、信息或出乎意料但可信的选择给场景提供能量。

当除了主角之外所有人都只是 delivery mechanism，场景就会掉能量。

## RG-06 · CHARACTER SURPRISE WITHIN CONSISTENCY / 一致性内的角色惊喜

鲜活人物往往会做出“足够意外，但又足够合理”的选择。

Mechanism 级例子：
- 最谨慎的人在风险变成实际问题时，反而第一个切掉无用仪式；
- 一直开玩笑的人在后果真正到来时突然极其精准；
- 新人抓到资深者遗漏；
- 表面阻碍者因为自身利益给出最干净的解决方案。

不要硬造怪癖。Surprise 应从目标、能力、历史、关系、信息和压力里长出来。

## RG-07 · TONAL CONTRAST / TENSION WAVE / 张力对比

持续最高压会变平。有效的低压 beat 可以承担：

- 关系质感；
- 幽默；
- 余波；
- 信息；
- false relief；
- setup；
- wonder；
- 安静的道德/情感识别。

Contrast 只有在它改变下一次高压 beat 的落点时才有功能。不要为了画波形塞 filler。

## RG-08 · CHARACTER-OWNED HUMOR / HUMANITY / 角色拥有的幽默与人味

当幽默适合当前作品时，优先让它来自：

- 熟人关系；
- 不兼容的 agenda；
- status mismatch；
- 专业/时代语言掉进尴尬的人类场景；
- 会改变互动的误解；
- 自利行为；
- 压力中的黑色幽默；
- 之前一句很自信的话后来获得新意义。

Humor 最好同时做到：展示声线/关系、改变意愿或张力、买/浪费时间、plant 信息、加强后续反转。

Profile 可以把 humor 设成 low/none。通用原则是：**人味属于角色和处境，不属于可拆卸的 narrator stand-up。**

## RG-09 · OPENING ORIENTATION + GRIP / 开头定位与抓力

开篇前段既要让读者知道“现在在哪、谁在干什么”，也应该给一个继续读的理由。

Grip 可以来自：
- active problem；
- contradiction；
- desire/cost；
- social friction；
- deadline；
- 一个不寻常的具体事实；
- voice/humor；
- 带电的关系状态；
- 来自真实信息边界的 mystery。

不要把“看不懂”当成“神秘”。

## RG-10 · FORWARD-PULL ENDING / 向前牵引的章尾

章节/场景结束时，通常应该留下 **changed state + 一个让大脑继续往前走的理由**。

合法机制：
- 不可逆后果；
- 具体的未决近程问题；
- planted issue 回来；
- recontextualization；
- 来人/消息/物件；
- 下一状态的声音/感知侵入；
- earned callback；
- 代价被延迟兑现的决定；
- 改变下一步的关系权限/义务。

拒绝抽象 narrator advertising。不要要求每章都有 twist。

## RG-11 · INFORMATION VALUE / 信息价值

信息应在它能改变理解、选择、期待或情绪意义时进入。

避免：
- 只为了填数据库字段的 exposition；
- 为廉价 mystery 故意扣着普通信息；
- reveal timing 与当前 action 无关。

好信息会改变读者模型，或改变角色的下一步。

## RG-12 · CAUSAL MOMENTUM / 因果动量

强场景的 meaningful beat 会改变下一步：

```text
cause
→ response
→ changed state
→ new decision/problem
```

只有时间顺序，不等于 momentum。

## RG-13 · RELATIONAL MOVEMENT / 关系移动

重要互动应该经常留下痕迹：

- trust 改变；
- permission 改变；
- obligation 出现；
- attraction/aversion 改变；
- status 被重新谈判；
- private fact 变成 shared knowledge；
- 一个人修改了对另一个人的模型。

不是每段对白都必须改变关系，但长篇里主要关系长期每场归零会让人物关系失去生命。

## RG-14 · SPECIFICITY OF STAKES / 具体化代价

Pressure 在代价具体到能改变选择时最有效。

优先：
- 能不能付出来的钱；
- 具有程序后果的 deadline；
- 正在冒险的关系权限；
- 会改变行动能力的伤；
- 可能灭失的 evidence；
- 已公开承诺、现在必须兑现的责任。

“所有东西都岌岌可危”远弱于可以执行的具体后果。

## RG-15 · SAFE-BUT-FLAT / 安全但无聊

正文技术上很干净，但下面多数成立时，Positive Quality Gate 仍应 Fail：

- 像正确动作的时间顺序报告；
- obstacle 第一次就解决，没有 tradeoff；
- dialogue 主要负责传必要信息；
- 角色声音能分辨，但不值得记；
- 没有有意义的 tonal contrast / human texture；
- 压力被宣布，但很少真正改变选择；
- climax 主要因为 outline 说“该高潮了”而到来；
- 状态变了，读者欲望没变；
- procedure 比 conflict/choice/consequence 占更多篇幅；
- 配角功能性静止。

修复应回 Reader Pressure / Scene Simulation / Character Simulation。不要靠随机 one-liner、碎句、形容词、假 twist、narrator hype 补能量。

# Profile Weighting

Profile 可以调：

```yaml
reader_grip: low|medium|high|very_high
serial_forward_pull: low|medium|high
reward_density: low|medium|high
humor: none|low|medium|high
mystery: low|medium|high
relationship_motion: low|medium|high
procedural_pleasure: low|medium|high
rhetorical_pleasure: low|medium|high
contemplative_space: low|medium|high
```

例：

- 高抓力商业连载强权重 RG-01/02/03/04/10/12；
- Cozy fiction 可以降低 threat pressure，提高 relationship/reward/voice；
- Literary fiction 可以允许更慢的 near-term propulsion，但仍要求高 interpretive/emotional specificity；
- Procedural fiction 只有在流程本身提供 competence、uncertainty、conflict、discovery 或 domain pleasure 时，才值得展开 procedure。

Profile 改阈值，不删除质量维度。
